В работе реализовано взаимодействие со страницей через DOM.
Для поиска элементов используются методы getElementById(), querySelector() и querySelectorAll().
1. Кнопка «Добавить прогноз» запрашивает описание и вероятность от 0 до 100. После проверки введённых данных новая карточка добавляется на страницу без перезагрузки.

2. Каждая карточка содержит описание, вероятность и кнопку «Удалить». При нажатии карточка удаляется со страницы.

3. Кнопка «Скрыть прогнозы» скрывает секцию с прогнозами. После этого текст кнопки меняется на «Показать прогнозы», и секцию можно вернуть.

4. Кнопка переключения темы меняет тёмную тему на светлую и обратно. Для изменения оформления используется CSS-класс light-theme.

5. Добавленные и удалённые прогнозы сохраняются в localStorage. Выбранная тема также сохраняется. После перезагрузки страницы данные и тема восстанавливаются.

6. Перед выполнением основных действий программа проверяет существование необходимых HTML-элементов. Ошибки выводятся в консоль браузера через console.error().
